# 물꼬 — 노후하수관로 정비 통합 설계 플랫폼 (공개판)

CCTV 정밀조사 조서를 읽어 노후하수관로 정비공사의 공법 판정(굴착/비굴착 VE), 수량·공사비, 도면 주석(DXF·LSP)을 만드는 설계 지원 프로그램입니다.

- 웹: 이 저장소의 GitHub Pages 주소로 접속하면 브라우저 안에서 바로 실행됩니다(stlite/Pyodide). 서버가 없어 올린 파일은 외부로 전송되지 않습니다.
- 단가: 공개판에는 **예시 단가**만 들어 있습니다. 실제 설계 단가는 사이드바의 단가 편집 또는 별도 단가 파일로 넣어 쓰십시오.
- 적용 매뉴얼: 환경부 2015 정밀조사 매뉴얼, 2017·2025 하수관로 표준매뉴얼.
